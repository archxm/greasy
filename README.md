# greasy
油猴脚本

## index_zhihu
- 需求说明
```
一直在用一个知名油猴脚本，来优化知乎，不过它有个bug，就是在浏览时，它突然滚动条自动下滑。
然后，我就不知道当前最后浏览的位置了。我一开始以为它是上滑了，后来发现是下滑。
因为它下滑，所以我就往上拉，一不小心就拉过头了，因为列表太长，滚动条定位就不太精准了，轻轻一拉，就很远。
而用键盘上下箭头慢慢滚动，又太慢。
所以，我就想着加个编号，这样似乎能够快速定位。
后来发现，光有编号不行，因为浏览内容时，我也不会记住编号。
然后就继续想，让编号在我浏览时间超过2秒，就变色。
这都是在AI帮助下，生成的代码，我也有少量修改。
```
